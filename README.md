# 📊 Sublytics - Subscription & Expense Tracker - UIKit

## 📱 About the Project

**Sublytics** is a native iOS application built with **UIKit** designed to help users track, analyze, and manage recurring subscriptions and expense schedules efficiently.

The application architecture follows the **MVVM** pattern with **Protocol-Oriented Programming**, clear separation of concerns in the service layer (mock services vs. cloud backend), and real-time data synchronization using **Firebase Firestore**.
